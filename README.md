# BGOpaqueLabel

An opaque, non-blended label for `UIKit` on iOS with full Emoji support.

## Usage

See "Example" project.

## Demo

![Screenshot](https://github.com/benguild/BGOpaqueLabel/raw/master/Screenshots/colored.png "Screenshot")

## Installation

`BGOpaqueLabel` is available through Swift Package Manager:

```swift
.package(url: "https://github.com/benguild/BGOpaqueLabel.git", from: "2.0.0")
```

From Objective-C, import with `@import BGOpaqueLabel;`. A subclass of it has to be written in Swift.
